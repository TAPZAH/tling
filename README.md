# TLing — офлайн-переводчик для Windows

**TLing** — настольный переводчик для Windows 10/11 (x64). Четыре офлайн-движка работают полностью локально на CPU, без интернета; дополнительно есть онлайн-перевод Google. Python не требуется. Есть установщик и портативная папка.

- Лицензия: **MIT**
- Репозиторий: [github.com/TAPZAH/tling](https://github.com/TAPZAH/tling)
- Версия: **beta 0.1003**

## Возможности

### Перевод текста
- Пять движков на выбор: **Argos**, **NLLB-200**, **Firefox Translations**, **MarianMT**, **Google (онлайн)**.
- Перевод в главном окне: введите текст, выберите «С языка» и «На язык», нажмите **«Перевести»**.
- **Автоопределение языка**: пункт «Авто» — язык определяется по тексту (офлайн-детектор на 60+ языков) с учётом установленных моделей; список сам переключается на найденный язык.
- **Перевод в обе стороны** при двух конкретных языках (надпись «переводит в обоих направлениях»).
- **Fallback-язык**: если «С языка» = «Авто» и определённый язык совпал с «На язык», перевод идёт на третий выбранный язык (поле появляется в главном окне).
- **Перевод через английский**, если для пары нет прямой модели.
- В окне перевода показывается **фактически использованное направление** (с учётом автоопределения), а не значения из настроек.

### Перевод выделенного текста
- **Кнопка у курсора** после выделения текста в любой программе (можно требовать удержание Ctrl/Alt/Shift или отключить кнопку).
- **Ctrl+C+C** — удерживайте Ctrl и дважды нажмите C. Режим «Только Ctrl+C+C» не перехватывает обычные Ctrl+C/Ctrl+V и не показывает кнопку.
- **Автокопирование** выделенного текста в буфер (по желанию).
- **Турбо-перевод**: переводить сразу после выделения, без кнопки у курсора.
- **Окно результата** рядом с курсором:
  - **Копировать**;
  - **Добавить** — оригинал + разделитель + перевод (разделитель настраивается: ` / ` или ` - `);
  - **Замена** — перевод вставляется в исходное приложение поверх выделения;
  - **О** (маленькая квадратная кнопка) — **показ оригинала**: переключает текст в окне между переводом и исходным текстом;
  - режим окна: «закрывать нажатием по окну» или «выделять часть текста, закрывать кнопкой Закрыть».

### Перевод области экрана (OCR)
- Выделение области мышью → распознавание текста → перевод в том же окне результата.
- Вызов: пункт трея **«Перевод области экрана»**, горячая клавиша **Ctrl+Shift+S** или кнопка **«Область экрана»**.
- Автоповорот изображения (0/90/180/270).
- **Движок OCR** (Настройки → Поведение): «Автоматически», **Tesseract**, **PaddleOCR (PP-OCR)**.
  - PaddleOCR точнее на фото и сканах; модели PP-OCR идут в комплекте (латиница и кириллица).
  - Для остальных языков — автоматический откат на Tesseract; языковые данные Tesseract скачиваются по запросу.
- **«Только OCR»** — распознавание без перевода:
  - пункт трея **«Только OCR (без перевода, до перезапуска)»** действует до перезапуска; при включении программа предупреждает об этом;
  - чтобы включить навсегда — чекбокс **«Только OCR всегда»** в Настройки → Поведение;
  - в этом режиме вместо перевода показывается распознанный оригинал с кнопкой «Копировать» и реально определённым языком; режим действует только для OCR области экрана.

### Перевод изображений
- Кнопка **«Изображение…»** в главном окне, пункт трея **«Перевести изображение…»** или плавающая кнопка.
- Поддерживаются PNG, JPG/JPEG, BMP, GIF, TIFF.
- Результат: **Word (.docx)** или **Excel (.xlsx)** с примерной разметкой (таблицы, колонки, размер шрифта, выравнивание) либо **PNG с переводом**: оригинальный текст затирается, перевод рисуется в тех же позициях (таблицы по колонкам, жирные заголовки, числа и валюта не переводятся).

### Перевод PDF
- Если у страницы есть текстовый слой — он берётся с координатами и начертанием (точно, без OCR).
- Если страница — скан: рендер и распознавание (OCR).
- Многостраничный PDF сохраняется в **один .docx** (страницы через разрыв) или **.xlsx**; для изображения — PNG по страницам.

### Перевод ячеек Excel
- Выделите ячейки в открытом Excel и вызовите перевод **горячей клавишей**.
- Базовая клавиша — **Alt+E**. Свою комбинацию можно задать в поле «Горячая клавиша Excel» (комбинация записывается нажатием).
- **Способ записи**: «Буфер обмена» (Excel должен быть в фокусе), «COM» (запись напрямую в открытый Excel, формулы не трогаются) или «Авто» (COM с откатом на буфер).
- Перевод добавляется к каждой выделенной ячейке через разделитель «Добавить к оригиналу».

### Плавающая кнопка
- Включается в трее или в настройках. Перетащите файл на кнопку — перевод начнётся сразу; двойной клик открывает выбор файла.
- Позицию кнопки можно перетаскивать (сохраняется).

### Прочее
- **История копирований** (1–50 записей, по умолчанию 10) в меню трея: копировать / перевести / очистить.
- **Трей**: открыть, история, автокопирование, турбо-перевод, проверка обновлений, перевод области экрана, перевод изображения, перевод ячеек Word/Excel, плавающая кнопка, «Только OCR», выход.
- **Светлая и тёмная темы** — единое оформление окна, настроек, меню и кнопки у курсора.
- **Многоязычный интерфейс**: русский, English, Deutsch, Français, Español (авто по языку системы).
- **Автозагрузка** вместе с Windows (Настройки → Поведение).
- **Проверка обновлений** через GitHub: при запуске (можно отключить) и вручную; окно с кнопками «Скачать и установить» / «Страница релизов».
- **Портативный режим**: настройки, журнал и модели рядом с exe.

## Настройки

Открываются кнопкой **«Настройки»** в главном окне. Разделы: **Языки**, **Поведение**, **Темы**, **Язык интерфейса**, **О программе**.

### Языки
- **Движок перевода**: Argos / NLLB-200 / Firefox / MarianMT / Google (онлайн).
- **Пакеты моделей…** — окно «Пакеты»: установка и удаление моделей Argos, NLLB-200, Firefox Translations, MarianMT. Онлайн-переводчику модели не нужны.
- **Ключ Google** (необязательно): с ключом — надёжнее; без ключа — бесплатные эндпоинты Google (могут ограничивать запросы). Ключ хранится в `settings.json` и передаётся только сервису Google.

### Поведение
- **Клавиша удержания для кнопки перевода**: не требуется / Ctrl / Alt / Shift.
- **Переводить выделенный текст по Ctrl+C+C** (вкл/выкл).
- **Только Ctrl+C+C** — не показывать кнопку при выделении.
- **Окно результата**: «Закрывать нажатием по окну» или «Выделять часть текста; закрывать кнопкой Закрыть».
- **Автоматически копировать выделенный текст в буфер обмена**.
- **Символ добавления к оригиналу**: ` / ` или ` - `.
- **Хранить последние копирования**: 1–50.
- **Запускать вместе с Windows**.
- **Excel: перевод выделенных ячеек**:
  - включить/выключить;
  - **Горячая клавиша Excel** (по умолчанию **Alt+E**; своя комбинация задаётся нажатием);
  - **Способ записи в Excel**: «Буфер обмена» / «COM» / «Авто».
- **Движок распознавания текста (OCR)**: «Автоматически (лучший доступный)» / Tesseract / PaddleOCR (PP-OCR).
- **Только OCR всегда** (распознавать область экрана без перевода).

### Темы
- **Светлая** / **Тёмная**. Тема применяется к главному окну, настройкам, меню и кнопке у курсора.

### Язык интерфейса
- **Авто (система)** или конкретный: русский, English, Deutsch, Français, Español, украинская. Изменение применяется сразу.

### О программе
- Версия и автор.
- **Проверить обновления**, **Скачать и установить**, **Страница релизов**.
- **Проверять обновления при запуске** (вкл/выкл).

## Горячие клавиши и жесты

| Действие | Как вызвать |
|---|---|
| Перевод области экрана | **Ctrl+Shift+S** (фиксированная), кнопка «Область экрана», пункт трея |
| Перевод выделенного текста | Кнопка у курсора; **Ctrl+C+C** (двойное Ctrl+C) |
| Excel: перевод ячеек | **Alt+E** (базовая, можно задать свою) |
| Закрыть окно результата | Esc или клик по окну (в режиме «клик закрывает») |

## Движки перевода

| Движок | Особенности |
|---|---|
| **Argos Translate** | Компактные офлайн-пакеты по парам языков; ставятся в «Пакетах». |
| **NLLB-200 Distilled 600M** | Одна модель Meta на ~200 языков (INT8, CTranslate2 + oneDNN); ~600 МБ. |
| **Firefox Translations** | Лёгкие модели Mozilla (tiny/base) через нативный Rust-движок. |
| **MarianMT** | Модели Helsinki-NLP OPUS-MT (CTranslate2), каталог Hugging Face. |
| **Google (онлайн)** | Через интернет: без ключа (бесплатные эндпоинты) или со своим API-ключом. |

## Модели и данные

- Модели перевода устанавливаются в окне **«Пакеты»** (нужен интернет) либо кладутся в портативную папку.
- **Модели OCR PaddleOCR (PP-OCR)** входят в комплект (латиница и кириллица); языковые данные Tesseract скачиваются по запросу.
- Каталог данных:
  - `%OFFLINE_TRANSLATOR_HOME%` (если задан),
  - иначе `<папка exe>\data` (портативный режим),
  - иначе `%USERPROFILE%\.local\share\offline-translator`.
- Файлы: `settings.json` (настройки), `app.log` (журнал), `tessdata` и `ppocr` (данные OCR).
- Для удаления программы достаточно удалить её папку / использовать деинсталлятор; настройки в профиле не трогаются.

## Требования

- Windows 10/11, 64-bit.
- Отдельно ставить Visual C++ Redistributable не нужно — нужные DLL лежат рядом с exe.
- Python не требуется.

## Установка

- **Установщик** `tling-0.1003-beta-setup.exe` — без моделей перевода (OCR включён); модели ставятся из окна «Пакеты».
- **Портативная папка** `tling-0.1003-beta-portable.zip` — распакуйте и запустите `TLing.exe`.
- **Исходники** `tling-0.1003-beta-src.zip`.

Сборки с предустановленными моделями собираются локально скриптом `cpp\build_release.ps1` и на GitHub не выкладываются.
