# TLing beta 0.99.7 — текст релиза для GitHub

## Tag

`v0.99.7-beta`

## Заголовок

TLing beta 0.99.7 — онлайн-перевод Google

## Описание

Версия 0.99.7 добавляет пятый движок — **онлайн-перевод Google**: он
работает без ключа API (через бесплатные эндпоинты) и включается в списке
движков вместе с офлайн-движками.

**TLing beta 0.99.7 — online Google translation.**

## Что нового

- **Движок «Google (онлайн)»** — перевод через сервис Google:
  - **без ключа** работает через бесплатные эндпоинты (`gtx`, запасной
    `clients5` — если первый ограничивает автоматические запросы);
  - **с ключом API** (необязательное поле на странице «Языки» в настройках)
    используется официальный API — надёжнее и без ограничений бесплатных
    эндпоинтов; ключ можно получить в Google Cloud.
  - Текст перевода уходит на сервер Google — это единственный движок,
    которому нужен интернет; офлайн-движки работают как раньше.
- Онлайн-движку не нужны модели: окно «Пакеты» для него показывает
  пояснение, а автоопределение языка работает как обычно.

## Что вошло ранее

- **Автоопределение языка источника** (офлайн-детектор на 60+ языков,
  пункт «Авто» в списке «С языка»); перевод выделенного текста уважает
  выбранные языки главного окна.
- **Турбо перевод** в меню трея: перевод сразу после выделения текста.
- **Список языков по алфавиту** с полосой прокрутки и прокруткой колесом.
- **Прозрачная иконка** приложения (ярлык, окна, трей, установщик).
- **Оборванные модели Firefox** больше не считаются установленными —
  приложение прямо говорит, какую модель доставить.
- Поддержка современных пакетов Argos (1.5+); 64 языка в списке.

## Установка

- `tling-0.99.7-beta-setup.exe` — установщик **без моделей** (~11 МБ): модели
  ставятся из окна «Пакеты».
- `tling-0.99.7-beta-portable.zip` — портативная папка без моделей (~15 МБ),
  Python не нужен.
- `tling-0.99.7-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.7**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` ~900 МБ и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
