# TLing beta 0.1000 — текст релиза для GitHub

## Tag

`v0.1000-beta`

## Заголовок

TLing beta 0.1000 — Excel, изображения и PDF

## Описание

**TLing** — оффлайн-переводчик для Windows. В версии 0.1000 добавлены
перевод выделенных ячеек Excel, перевод изображений и PDF в Word/Excel с
примерной разметкой, плавающая кнопка для перетаскивания файлов; интерфейс —
единая светлая/тёмная тема.

**TLing beta 0.1000 — Excel, image and PDF translation, refreshed UI.**

## Что нового

- **Перевод PDF** (PDFium, BSD): если у страницы есть текстовый слой —
  берём его с координатами и начертанием (точно, без OCR); если скан —
  рендер страницы и распознавание. Многостраничный PDF — один `.docx`
  (страницы через разрыв) или `.xlsx`.
- **Перевод изображений**: кнопка «Изображение…», трей и «Область экрана →
  Word/Excel». Вывод в Word/Excel с примерной разметкой (таблицы, колонки,
  размер шрифта, выравнивание) либо в **картинку с переводом** (оригинал
  затирается, текст рисуется как в оригинале; перенос — только при нехватке
  ширины). Автоповорот скана (0/90/180/270).
- **Автоопределение языка документа** для OCR и повторное распознавание
  нужным языком (например, турецким), данные OCR ставятся по запросу.
- **Перевод выделенных ячеек Excel** (горячая клавиша или двойное Ctrl+C):
  COM — напрямую в открытый Excel, формулы не трогаются; либо через буфер
  обмена; авто-режим с откатом.
- **Кнопка «Добавить»** в окне перевода — оригинал + перевод через
  настраиваемый разделитель (` / ` или ` - `).
- **Плавающая кнопка** (включается в меню трея): перетащите файл — перевод
  начнётся сразу; двойной клик открывает выбор файла.
- **Своё окно проверки обновлений** в стиле приложения с кнопками «Да»/«Нет».
- **Единое оформление**: светлая и тёмная темы, заголовок окна следует теме,
  современный системный шрифт.
- Убраны отдельная горячая клавиша перевода выделения (остались Ctrl+C+C и
  кнопка у курсора) и пункт автозагрузки из меню трея (остался в настройках).

## Что вошло в предыдущих версиях

- **Перевод области экрана (OCR)** — выделите рамкой текст на экране, он
  распознаётся офлайн (Tesseract) и переводится.
- **Проверка обновлений при запуске** — тихо, отключается чекбоксом.
- **Направление перевода** — в обе стороны; при «С языка» = «Авто» есть
  третий список для случая, когда язык текста совпал с «На язык».
- **Движок «Google (онлайн)»** — без ключа или со своим ключом API.
- **Автоопределение языка источника**, турбо-перевод, история копирований,
  многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.1000-beta-setup.exe` — установщик **без моделей**: движки и
  языковые данные OCR ставятся из окна «Пакеты» / по запросу.
- `tling-0.1000-beta-portable.zip` — портативная папка без моделей,
  Python не нужен.
- `tling-0.1000-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.1000**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
