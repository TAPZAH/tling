# TLing beta 0.99.4 — текст релиза для GitHub

## Tag

`v0.99.4-beta`

## Заголовок

TLing beta 0.99.4 — новые пакеты Argos и полный список языков

## Описание

Версия 0.99.4 исправляет работу с современными пакетами Argos и дополняет
список языков теми, для которых Argos публикует модели.

**TLing beta 0.99.4 — newer Argos packages and a complete language list.**

## Исправлено

- **Современные пакеты Argos (1.5+) не распознавались.** В них нет
  `model/config.json`, а словарь лежит в `shared_vocabulary.txt`; приложение
  требовало старый состав файлов, поэтому уже установленный пакет выглядел
  отсутствующим и перевод отвечал «установите модель». Теперь принимаются оба
  формата.
- **В списке языков окна не было языков, которые предлагает Argos:**
  эсперанто, баскский, ирландский, киргизский, португальский (Бразилия),
  суахили, тагальский и китайский (традиционный). Все восемь добавлены
  (вместе с кодами NLLB) — теперь в списке 64 языка.

## Проверено

- Перевод через английский для пар без прямой модели: проверен на реальных
  моделях (эсперанто → английский → русский).
- Регрессионные тесты пивота и NLLB теперь действительно выполняются в
  релизной сборке (раньше они были отключены директивой `NDEBUG`) — попутно
  исправлено устаревшее ожидание в тесте маршрута.

## Установка

- `tling-0.99.4-beta-setup.exe` — установщик **без моделей** (~11 МБ): модели
  ставятся из окна «Пакеты».
- `tling-0.99.4-beta-portable.zip` — портативная папка без моделей (~15 МБ),
  Python не нужен.
- `tling-0.99.4-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.4**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` ~900 МБ и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
