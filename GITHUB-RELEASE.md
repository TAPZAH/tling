# TLing beta 0.1001 — текст релиза для GitHub

## Tag

`v0.1001-beta`

## Заголовок

TLing beta 0.1001 — OCR на PaddleOCR и переключатель движка

## Описание

**TLing** — оффлайн-переводчик для Windows. В версии 0.1001 распознавание
текста для области экрана, изображений и сканов PDF переведено на
**PaddleOCR (PP-OCR)** через ONNX Runtime — точнее на фото и сканах. Движок
OCR переключается в настройках; Tesseract остаётся запасным.

**TLing beta 0.1001 — PaddleOCR-based OCR and an OCR engine switch.**

## Что нового

- **OCR на PaddleOCR (PP-OCR)**: детектор строк DBNet и распознаватели по
  письменностям (латиница и кириллица) вместо текстовых боксов Tesseract —
  заметно чище на фотографиях и сканах. Инференс — ONNX Runtime (MIT),
  модели PP-OCR (Apache-2.0) входят в поставку (`data/ppocr`).
- **Переключатель движка OCR** в настройках («Поведение»): «Автоматически»,
  «Tesseract», «PaddleOCR». Для языков без моделей PP-OCR — автоматический
  откат на Tesseract.
- **Автоопределение ориентации** страницы (0/90/180/270) и отдельной строки
  (0/180) моделями PP-LCNet.
- **Смешанный текст**: на странице с латиницей и кириллицей движок выбирает
  письменность по уверенности, а отдельные строки могут переключаться.

## Что вошло в предыдущих версиях

- **Перевод PDF** (PDFium, BSD): текстовый слой берётся с координатами и
  начертанием (без OCR); скан — рендер и распознавание. Многостраничный PDF —
  один `.docx` или `.xlsx`.
- **Перевод изображений**: вывод в Word/Excel с примерной разметкой или в
  картинку с переводом (оригинал затирается, текст рисуется как в оригинале).
- **Перевод выделенных ячеек Excel** (горячая клавиша или двойное Ctrl+C):
  COM — напрямую в открытый Excel; либо через буфер обмена; авто-режим.
- **Перевод области экрана (OCR)**, кнопка «Добавить», плавающая кнопка,
  единая светлая/тёмная тема, проверка обновлений, история копирований,
  автоопределение языка, турбо-перевод, многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.1001-beta-setup.exe` — установщик **без моделей перевода**: OCR
  (PP-OCR) включён; движки и остальное — из окна «Пакеты» / по запросу.
- `tling-0.1001-beta-portable.zip` — портативная папка без моделей перевода
  (OCR включён), Python не нужен.
- `tling-0.1001-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.1001**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
