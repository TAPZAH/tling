TLing beta 0.99.7 — онлайн-перевод Google

## Описание

**TLing** — оффлайн-переводчик для Windows. В версии 0.99.7 появился пятый
движок — **Google (онлайн)**: он работает даже без ключа API и выбирается в
списке движков вместе с офлайн-движками.

**TLing beta 0.99.7 — online Google translation alongside four offline
engines.**

## Что нового

- **Движок «Google (онлайн)»**:
  - **без ключа** — перевод через бесплатные эндпоинты Google (если один
    ограничивает автоматические запросы, используется запасной);
  - **с ключом API** — необязательное поле в настройках (Настройки → Языки):
    используется официальный API Google, он надёжнее; ключ можно создать в
    Google Cloud и вставить в это поле. Ключ хранится только в вашем
    `settings.json`;
  - онлайн-движку не нужны модели: окно «Пакеты» для него показывает
    пояснение, автоопределение языка работает как обычно.
- **Внимание:** это единственный движок, которому нужен интернет — текст
  перевода отправляется на сервер Google. Четыре офлайн-движка (Argos,
  NLLB-200, Firefox, MarianMT) работают как раньше, без сети.

## Что вошло в предыдущих версиях

- **Автоопределение языка источника** — офлайн-детектор на 60+ языков,
  пункт «Авто» в списке «С языка»; перевод выделенного текста учитывает
  выбранные языки главного окна.
- **Турбо перевод** в меню трея — перевод сразу после выделения текста.
- **Список языков по алфавиту** (64 языка) с полосой прокрутки; список
  открывается с начала.
- **Прозрачная иконка** приложения — на ярлыке, в окнах, в трее и у
  установщика.
- **Оборванные модели Firefox** больше не считаются установленными:
  приложение прямо говорит, какую модель доставить, и предлагает открыть
  «Пакеты» с фильтром по нужному языку.
- **Современные пакеты Argos (1.5+)** распознаются; добавлены языки, для
  которых Argos публикует модели (эсперанто, баскский, ирландский,
  киргизский, португальский (Бразилия), суахили, тагальский, китайский
  (традиционный)).
- **Сводка «Сейчас работает»** на вкладке «Поведение» в настройках.
- **Проверка обновлений из трея** показывает результат всплывающим
  сообщением, не открывая настройки.

## Установка

- `tling-0.99.7-beta-setup.exe` — установщик **без моделей** (~11 МБ): модели
  ставятся из окна «Пакеты».
- `tling-0.99.7-beta-portable.zip` — портативная папка без моделей (~15 МБ),
  Python не нужен.
- `tling-0.99.7-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.7**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` ~900 МБ и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
