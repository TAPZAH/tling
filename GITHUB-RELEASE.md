**TLing** — оффлайн-переводчик для Windows. В версии 0.1006 экспорт в Excel
и Word перестроен на реальную сетку таблиц, добавлен точный режим OCR.

**TLing beta 0.1006 — table-aware Excel/Word export and accurate OCR mode.**

## Что нового

- **Перевод документов в Excel/Word по сетке таблиц**: границы колонок и
  строк ищутся по линиям на скане, ячейки соответствуют оригиналу —
  объединённые поля (шапка покупателя, товарная строка), переносы строк
  внутри ячейки, настоящие `merged cells` и границы в `.xlsx`, `gridSpan`
  и `vMerge` в `.docx`, ширины колонок и высота строк из геометрии
  страницы. Числа и суммы остаются числами, ИНН/коды — текстом
  (ведущие нули сохраняются).
- **Режим «Точно» для OCR** (Настройки → Документы): серверный детектор
  PP-OCRv5 (~87 МБ, скачивается один раз по запросу) — точнее читает шапки,
  мелкие поля и сканы; CLI-ключ `--ocr-quality accurate|fast`.
- **Китайский OCR (PP-OCR)**: распознавание китайских иероглифов (в 0.1005);
  шапки документов теперь читаются без ошибок, подписи полей переводятся.
- Наложение перевода на картинку: фон берётся по всей области, серые
  плашки убраны; детектор не склеивает соседние поля и строки.

## Что вошло в предыдущих версиях

- **Excel**: базовая горячая клавиша — **Alt+E**, свою можно задать.
- **Кнопка «показ оригинала» («О»)** в окне перевода; установка старых
  пакетов Argos (v1.0); режим «Только OCR»; перевод PDF (PDFium),
  изображений в Word/Excel и PNG, ячеек Excel (COM/буфер), плавающая
  кнопка, темы, обновления, история, автоопределение языка, турбо-перевод,
  многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.1006-beta-setup.exe` — установщик **без моделей перевода**: OCR
  (PP-OCR) включён; движки и остальное — из окна «Пакеты» / по запросу.
- `tling-0.1006-beta-portable.zip` — портативная папка без моделей перевода
  (OCR включён), Python не нужен.
- `tling-0.1006-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.1006**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
