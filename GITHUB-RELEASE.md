# TLing beta 0.99 — текст релиза для GitHub

## Tag

`v0.99-beta`

## Заголовок

TLing beta 0.99 — оффлайн-переводчик для Windows

## Описание

Первый публичный релиз **TLing** под новым именем: оффлайн-перевод
с четырьмя движками, многоязычным интерфейсом и установщиком с моделями.

**TLing beta 0.99 — offline translator for Windows with four engines,
a multilingual UI and model-bundled installer.**

### Главное

- **Четыре оффлайн-движка:** Argos Translate, NLLB-200 Distilled 600M
  (INT8, CTranslate2 + oneDNN), Firefox Translations (Rust-движок
  `fxtranslate`), MarianMT (Helsinki-NLP OPUS-MT).
- **Перевод в окне, из трея и по выделенному тексту**; кнопка у курсора,
  Ctrl+C+C, настраиваемая клавиша удержания.
- **Кнопка «Замена»** — вставка перевода в исходное приложение поверх
  выделения.
- **История копирований** и **автокопирование выделения** (в том числе из
  меню трея).
- **Интерфейс на 5 языках** (русский, English, Deutsch, Français, Español)
  с автоопределением по системе и переключением в «Настройки → Язык
  интерфейса».
- **Светлая и тёмная темы**, включая заголовки окон.
- **Один экземпляр приложения**, автозагрузка, проверка обновлений.
- Полностью **нативный C++ (Win32) + Rust-мост** — Python не требуется.

### Установка

- `tling-0.99-beta-setup.exe` — установщик с моделями (Argos en↔ru и
  NLLB-200 600M): после установки всё работает оффлайн сразу.
- `tling-0.99-beta-portable.zip` — портативная папка без моделей: модели
  ставятся из окна «Пакеты».
- `tling-0.99-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Автор — TAP3AH.

Полный портатив с моделями (`portable-with-models.zip`) собирается локально
скриптом `cpp\build_release.ps1` и на GitHub не выкладывается.
