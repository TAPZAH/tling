# TLing beta 0.99.3 — текст релиза для GitHub

## Tag

`v0.99.3-beta`

## Заголовок

TLing beta 0.99.3 — турбо перевод и исправления по аудиту

## Описание

Версия 0.99.3 добавляет **турбо-перевод** и исправления, найденные при аудите
кода: обновление с GitHub, безопасная распаковка ZIP, корректные горячие
клавиши и проверка моделей Firefox.

**TLing beta 0.99.3 — turbo translation and audit fixes.**

## Что нового

- **Турбо перевод** — перевод выделенного текста сразу после выделения, без
  кнопки у курсора и без двойного Ctrl+C. Включается и выключается в меню
  трея (правый клик по иконке), состояние сохраняется в настройках.
- **Проверка обновлений из трея больше не открывает настройки**: результат
  приходит всплывающим сообщением у иконки (найдено обновление / обновлений
  нет / ошибка), а окно настроек открывается только когда обновление
  найдено — сразу на странице «О программе» и активной кнопкой установки.
- **Возвращена сводка «Сейчас работает»** вверху вкладки «Поведение» в
  настройках: компактно перечисляет выбранные способы перевода и обновляется
  сразу при изменении любой опции на странице.

## Исправлено

- **Проверка обновлений переставала работать после первого запуска**: ответ
  GitHub сохранялся во временный файл и больше не перечитывался, поэтому
  новые релизы не показывались никогда.
- **Установка пакетов Argos**: разбор ZIP больше не переполняется в 32-битной
  арифметике (проверка границ проходила, а чтение уходило за пределы
  буфера), добавлена проверка CRC32 и соответствия размера, а «zip-бомбы»
  отклоняются.
- **Битый хоткей в `settings.json`** (например «F999999999») больше не
  сбрасывает все настройки приложения.
- **Оборванные файлы моделей Firefox** (zstd) больше не устанавливаются как
  готовые.
- **Ошибка при загрузке моделей Firefox** на чистой установке: каталога
  `firefox-models` ещё нет, и перечисление установленных моделей падало с
  `directory_iterator`.
- **Исключения из оконных процедур** настроек и окна перевода больше не
  приводят к аварийному завершению приложения.
- Устранена гонка между фоновым сторожем и GUI-потоком при чтении настроек.
- Прочие мелочи после аудита: корректный разбор именованных диапазонов в
  `check_package.ps1` на неанглоязычной Windows.

## Установка

- `tling-0.99.3-beta-setup.exe` — установщик **без моделей** (~11 МБ): модели
  ставятся из окна «Пакеты».
- `tling-0.99.3-beta-portable.zip` — портативная папка без моделей (~15 МБ),
  Python не нужен.
- `tling-0.99.3-beta-src.zip` — исходники.

Обновление с 0.99.2 получает��я автоматически: в 0.99.2 перестанет работать
проверка обновлений (исправлено в 0.99.3), поэтому для перехода на эту версию
скачайте установщик вручную.

Нужны Windows 10/11 x64. Версия **beta 0.99.3**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` ~900 МБ и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
