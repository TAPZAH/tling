# TLing beta 0.99.8 — текст релиза для GitHub

## Tag

`v0.99.8-beta`

## Заголовок

TLing beta 0.99.8 — перевод выделенной области экрана

## Описание

**TLing** — оффлайн-переводчик для Windows. В версии 0.99.8 появился
**перевод области экрана**: выделите рамкой любой текст на экране — он
распознаётся офлайн (Tesseract OCR) и переводится в привычном окне
результата. Кроме этого поправлено направление перевода для двух языков и
чёткость интерфейса на мониторах с масштабированием.

**TLing beta 0.99.8 — translate a selected screen region via built-in OCR,
plus smarter translation direction and crisp UI on scaled displays.**

## Что нового

- **Перевод области экрана (OCR)**:
  - выделите прямоугольную область на экране — она распознаётся **офлайн**
    движком **Tesseract** (никакой сети) и переводится выбранным движком;
  - вызов: пункт трея «Перевод области экрана», горячая клавиша
    **Ctrl+Shift+S** или кнопка «Область экрана» в главном окне;
  - экран замораживается, лишнее затемняется, `Esc` (или правая кнопка)
    отменяет выделение;
  - распознавание идёт на языке, выбранном в «С языка» (для «Авто» —
    английский), затем текст переводится как обычное выделение;
  - в этом режиме кнопка «Замена» скрыта — заменять в исходном окне нечего;
  - **языковые данные OCR скачиваются по требованию**: при первом
    использовании нового языка приложение предлагает скачать небольшой файл
    `*.traineddata` (обычно 0,4–8 МБ) с GitHub; поддержаны 63 языка из 64
    (нет данных для тагальского `tl`).
- **Направление перевода**:
  - при двух конкретных языках перевод работает **в обе стороны** — рядом
    выводится подсказка «переводит в обоих направлениях»; если введён текст
    на языке «На язык», направление меняется автоматически (например,
    С=английский, На=русский, русский текст → переводится на английский);
  - при «С языка» = **«Авто»** появляется третий список: на какой язык
    переводить, если определённый язык совпал с «На язык».
- **Чёткий интерфейс на масштабировании**: включено GDI-масштабирование DPI,
  из-за которого раньше на 125/150% весь интерфейс и шрифты выглядели
  размытыми. Окно выделения области работает в физических пикселях, поэтому
  рамка больше не «приближается» и не обрезает половину экрана.
- **Проверка обновлений при запуске**: через несколько секунд после старта
  программа тихо проверяет GitHub Releases. Если обновлений нет — никаких
  уведомлений; если есть — предлагает скачать и установить сейчас же.
  Отключается чекбоксом «Проверять обновления при запуске»
  (Настройки → О программе).

## Что вошло в предыдущих версиях

- **Движок «Google (онлайн)»** — без ключа или со своим ключом API.
- **Автоопределение языка источника** — офлайн-детектор на 60+ языков,
  пункт «Авто» в списке «С языка».
- **Турбо перевод** в меню трея — перевод сразу после выделения текста.
- **Список языков по алфавиту** (64 языка) с полосой прокрутки.
- **Оборванные модели Firefox** больше не считаются установленными:
  приложение подсказывает, какую модель доставить.
- **Современные пакеты Argos (1.5+)** распознаются; добавлены языки Argos.
- **Прозрачная иконка** приложения, светлая/тёмная темы, автозагрузка,
  проверка обновлений через GitHub Releases.

## Установка

- `tling-0.99.8-beta-setup.exe` — установщик **без моделей**: движки и
  языковые данные OCR ставятся из окна «Пакеты» / по запросу.
- `tling-0.99.8-beta-portable.zip` — портативная папка без моделей,
  Python не нужен.
- `tling-0.99.8-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.8**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
