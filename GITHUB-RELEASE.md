**TLing** — оффлайн-переводчик для Windows. В версии 0.1007 перевод документов
в Excel и Word строится по реальной сетке таблиц, добавлен точный режим OCR,
исправлен экспорт в Word и поворот PNG с наложением перевода.

**TLing beta 0.1007 — table-aware Excel/Word export, accurate OCR, rotation and direction fixes.**

## Что нового

- **Excel/Word по сетке таблиц**: границы колонок и строк ищутся по линиям на
  скане — объединённые ячейки, переносы внутри ячейки, `merged cells` и границы
  в `.xlsx`, `gridSpan`/`vMerge` в `.docx`, ширины колонок и высота строк из
  геометрии. Числа остаются числами, ИНН/коды — текстом (ведущие нули целы).
- **Режим «Точно» для OCR** (Настройки → Документы): серверный детектор
  PP-OCRv5 (~87 МБ, скачивается один раз) — точнее читает шапки и мелкие поля;
  CLI-ключ `--ocr-quality accurate|fast`.
- **Исправлен экспорт в Word**: файл больше не считается повреждённым
  (был баг с таблицей в конце документа).
- **PNG с переводом поворачивается** в читаемую ориентацию (сканы боком).
- **Направление перевода фиксируется на весь документ**: смешанные ячейки
  (артикулы, «ET», латиница) больше не уезжают в обратную сторону ru↔en;
  резервный язык при совпадении языка с целью применяется один раз.
- **Китайский OCR (PP-OCR)** и докачка модели по запросу (с 0.1005).

## Что вошло в предыдущих версиях

- **Excel**: базовая горячая клавиша — **Alt+E**, свою можно задать.
- **Кнопка «показ оригинала» («О»)** в окне перевода; установка старых
  пакетов Argos (v1.0); режим «Только OCR»; перевод PDF (PDFium),
  изображений в Word/Excel и PNG, ячеек Excel (COM/буфер), плавающая
  кнопка, темы, обновления, история, автоопределение языка, турбо-перевод,
  многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.1007-beta-setup.exe` — установщик **без моделей перевода**: OCR
  (PP-OCR) включён; движки и остальное — из окна «Пакеты» / по запросу.
- `tling-0.1007-beta-portable.zip` — портативная папка без моделей перевода
  (OCR включён), Python не нужен.
- `tling-0.1007-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.1007**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
