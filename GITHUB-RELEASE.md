## Описание

Обновление **TLing** добавляет турбо-перевод, иконку приложения и ярлыки при
установке, а также исправления по итогам аудита кода.

**TLing beta 0.99.2 — turbo translation, app icon, shortcuts and audit fixes.**

### Что нового

- **Турбо перевод** — перевод выделенного текста сразу после выделения, без
  кнопки у курсора и без двойного Ctrl+C. Включается и выключается в меню
  трея (правый клик по иконке), состояние сохраняется в настройках.
- **Иконка приложения** встроена в `TLing.exe`: ярлыки, панель задач и
  Проводник больше не показывают стандартную заглушку.
- **Иконка окна** — та же иконка в заголовке окна и на панели задач.
- **Ярлык на рабочем столе** теперь создаётся по умолчанию (ярлык в меню
  Пуск был и раньше).
- Новые иконки светлой/тёмной темы и мультиразмерный `app.ico` (16–256).

### Исправлено

- **Проверка обновлений переставала работать после первого запуска**: ответ
  GitHub кэшировался во временном файле и больше не перечитывался, новые
  релизы не показывались никогда.
- **Установка пакетов Argos** падала с ошибкой «Неизвестный символ
  Huffman»: распаковка ZIP переведена на **zlib**, а чтение структуры ZIP
  теперь проверяет границы без переполнения 32-битной арифметики, сверяет
  CRC32 и отклоняет «zip-бомбы».
- **Битый хоткей в settings.json** («F999999999») сбрасывал все настройки
  приложения.
- **Оборванные файлы моделей Firefox** (zstd) больше не устанавливаются как
  готовые.
- **Ошибка при загрузке моделей Firefox** на чистой установке: каталога
  `firefox-models` ещё нет, и перечисление установленных моделей падало.
- **Исключения из оконных процедур** настроек и попапа перевода больше не
  приводят к аварийному завершению.
- Устранена гонка между фоновым сторожем и GUI при чтении настроек.

### Установка

- `tling-0.99.2-beta-setup.exe` — установщик без моделей: модели ставятся
  из окна «Пакеты».
- `tling-0.99.2-beta-portable.zip` — портативная папка без моделей.
- `tling-0.99.2-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.2**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` ~900 МБ и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
