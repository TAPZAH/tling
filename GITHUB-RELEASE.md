**TLing** — оффлайн-переводчик для Windows. В версии 0.1004 исправлена
установка старых пакетов Argos Translate.

**TLing beta 0.1004 — legacy Argos package installation fix.**

## Что нового

- **Установка старых пакетов Argos (v1.0)**: архивы, внутри которых файлы
  лежат в каталоге вида `ar_en` (а не `translate-ar_en-1_0`), теперь
  устанавливаются корректно. Раньше появлялась ошибка «В архиве Argos нет
  каталога пакета».
- Добавлен тест на установку пакета старого формата.

## Что вошло в предыдущих версиях

- **Кнопка «показ оригинала» («О»)** в окне перевода: не закрывает окно,
  не перекрывается, в цветах темы; переключает оригинал/перевод.
- **Excel**: базовая горячая клавиша — **Alt+E**, свою можно задать;
  вариант «двойное Ctrl+C» убран.
- **Режим «Только OCR»**: распознавание области экрана без перевода.
- **OCR на PaddleOCR (PP-OCR)** через ONNX Runtime, переключатель движка OCR,
  откат на Tesseract.
- **Перевод PDF** (PDFium), **перевод изображений** в Word/Excel и PNG
  с наложением, **перевод ячеек Excel** (COM/буфер), плавающая кнопка,
  темы, обновления, история, автоопределение языка, турбо-перевод,
  многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.1004-beta-setup.exe` — установщик **без моделей перевода**: OCR
  (PP-OCR) включён; движки и остальное — из окна «Пакеты» / по запросу.
- `tling-0.1004-beta-portable.zip` — портативная папка без моделей перевода
  (OCR включён), Python не нужен.
- `tling-0.1004-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.1004**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
