**TLing** — оффлайн-переводчик для Windows. В версии 0.1005 добавлен
китайский OCR и улучшен перевод картинок.

**TLing beta 0.1005 — Chinese OCR and image translation improvements.**

## Что нового

- **Китайский OCR (PP-OCR)**: распознавание китайских иероглифов (счёт-фактуры,
  упаковочные листы, письма). Модель (~81 МБ) скачивается один раз по запросу —
  диалог в GUI или автоматически в CLI. В режиме «Авто» подключается, когда
  модель уже установлена.
- **Excel и картинки**: если текст уже на языке перевода (например русский в
  английский документ), берётся резервный язык — вместо «ru→ru» без изменений.
- **Наложение перевода на изображение**: фон под текстом подбирается по всей
  области, а не по рамке — больше нет серых плашек на светлых документах.
- **Точнее детектор строк**: мелкие сканы повышаются до большего размера,
  читаются строки, которые раньше терялись.

## Что вошло в предыдущих версиях

- **Установка старых пакетов Argos (v1.0)**: архивы с каталогами вида `ar_en`
  устанавливаются корректно.
- **Кнопка «показ оригинала» («О»)** в окне перевода: не закрывает окно,
  не перекрывается, в цветах темы; переключает оригинал/перевод.
- **Excel**: базовая горячая клавиша — **Alt+E**, свою можно задать;
  вариант «двойное Ctrl+C» убран.
- **Режим «Только OCR»**: распознавание области экрана без перевода.
- **OCR на PaddleOCR (PP-OCR)** через ONNX Runtime, переключатель движка OCR,
  откат на Tesseract.
- **Перевод PDF** (PDFium), **перевод изображений** в Word/Excel и PNG
  с наложением, **перевод ячеек Excel** (COM/буфер), плавающая кнопка,
  темы, обновления, история, автоопределение языка, турбо-перевод,
  многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.1005-beta-setup.exe` — установщик **без моделей перевода**: OCR
  (PP-OCR) включён; движки и остальное — из окна «Пакеты» / по запросу.
- `tling-0.1005-beta-portable.zip` — портативная папка без моделей перевода
  (OCR включён), Python не нужен.
- `tling-0.1005-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.1005**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
