# TLing beta 0.99.9 — текст релиза для GitHub

## Tag

`v0.99.9-beta`

## Заголовок

TLing beta 0.99.9 — обновлённый интерфейс

## Описание

**TLing** — оффлайн-переводчик для Windows. В версии 0.99.9 переработан
внешний вид: единая светлая/тёмная тема для всего приложения, современный
шрифт, аккуратные выпадающие списки и кнопки, а заголовок окна теперь
окрашивается в цвет темы.

**TLing beta 0.99.9 — refreshed, consistent light/dark UI across the whole
application.**

## Что нового

- **Единое оформление приложения**:
  - **светлая тема** — белый фон и заголовок окна, чёрный текст;
  - **тёмная тема** — тёмный фон и заголовок, светлый текст;
- **Заголовок окна следует теме** на всех актуальных версиях Windows
  (Windows 10 1809+ и Windows 11) — раньше он оставался светлым в тёмной
  теме;
- **Современный шрифт интерфейса** (системный Segoe UI) во всём приложении
  вместо устаревшего растрового шрифта;
- **Перерисованы выпадающие списки и кнопки** (главное окно, настройки,
  «Пакеты») — они больше не выбиваются светлыми пятнами из тёмной темы;
- мягкие цвета темы и аккуратные рамки вместо «чистого» чёрного/белого.

## Что вошло в предыдущих версиях

- **Перевод области экрана (OCR)** — выделите рамкой текст на экране, он
  распознаётся офлайн (Tesseract) и переводится; вызов: трей,
  Ctrl+Shift+S или кнопка «Область экрана».
- **Проверка обновлений при запуске** — тихо, без уведомлений при
  отсутствии обновлений; отключается чекбоксом в настройках.
- **Направление перевода** — при двух конкретных языках перевод работает в
  обе стороны; при «С языка» = «Авто» есть третий список для случая, когда
  язык текста совпал с «На язык».
- **Движок «Google (онлайн)»** — без ключа или со своим ключом API.
- **Автоопределение языка источника**, турбо-перевод, история копирований,
  многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.99.9-beta-setup.exe` — установщик **без моделей**: движки и
  языковые данные OCR ставятся из окна «Пакеты» / по запросу.
- `tling-0.99.9-beta-portable.zip` — портативная папка без моделей,
  Python не нужен.
- `tling-0.99.9-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.9**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
