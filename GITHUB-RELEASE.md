**TLing** — оффлайн-переводчик для Windows. В версии 0.1002 добавлен режим
распознавания без перевода («Только OCR») и кнопка показа оригинала в окне
перевода.

**TLing beta 0.1002 — OCR-only mode and show-original toggle.**

## Что нового

- **Режим «Только OCR»**: распознавание области экрана без перевода — в окне
  результата показывается исходный текст с кнопкой «Копировать».
  - Включается пунктом трея «Только OCR (без перевода, до перезапуска)» —
    действует до перезапуска, программа предупреждает об этом.
  - Чтобы включить навсегда — чекбокс «Только OCR всегда» в
    Настройки → Поведение.
- **Кнопка «показ оригинала»** в окне перевода: маленькая квадратная кнопка
  «О» переключает текст между переводом и оригиналом; «Копировать» копирует
  то, что показано.
- **Реальная языковая пара в окне перевода**: показывается фактически
  использованное направление (с учётом автоопределения), а не значения из
  настроек.
- Пункт трея «Область экрана → Word/Excel» переименован в
  «Перевод ячеек Word/Excel».

## Что вошло в предыдущих версиях

- **OCR на PaddleOCR (PP-OCR)** через ONNX Runtime: детектор строк DBNet и
  распознаватели по письменностям (латиница, кириллица); переключатель
  движка OCR в настройках, откат на Tesseract для остальных языков.
- **Перевод PDF** (PDFium, BSD): текстовый слой или OCR скана; многостраничный
  PDF — один `.docx`/`.xlsx`.
- **Перевод изображений** в Word/Excel или PNG с наложением перевода
  (замена текста в тех же позициях, таблицы по колонкам, жирные заголовки).
- **Перевод выделенных ячеек Excel** (COM/буфер, горячая клавиша или Ctrl+C+C).
- Перевод области экрана, кнопка «Добавить», плавающая кнопка, темы,
  проверка обновлений, история копирований, автоопределение языка,
  турбо-перевод, многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.1002-beta-setup.exe` — установщик **без моделей перевода**: OCR
  (PP-OCR) включён; движки и остальное — из окна «Пакеты» / по запросу.
- `tling-0.1002-beta-portable.zip` — портативная папка без моделей перевода
  (OCR включён), Python не нужен.
- `tling-0.1002-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.1002**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
