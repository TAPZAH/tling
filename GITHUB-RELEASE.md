# TLing beta 0.99.5 — текст релиза для GitHub

## Tag

`v0.99.5-beta`

## Заголовок

TLing beta 0.99.5 — все языки в списке и загрузка модели в один клик

## Описание

Версия 0.99.5 исправляет выпадающие списки языков в главном окне и
предлагает скачать модель, если для выбранной пары её нет.

**TLing beta 0.99.5 — full language list and one-click model download.**

## Что нового

- **Новая иконка приложения** (жёлтая и синяя стрелки на прозрачном
  фоне) — на ярлыке, в окнах, в трее и у установщика.
- **Список языков стал удобнее**: пункты идут по алфавиту, у списка есть
  **полоса прокрутки и прокрутка колесом** (раньше её не было — дальние
  языки было не достать), а выпадающий список всегда открывается с начала —
  «Авто» и первые языки видны сразу.
- **Автоопределение языка источника**: в списке «С языка» появился пункт
  «Авто» — язык определяется по тексту **настоящим офлайн-детектором
  (60+ языков)** с учётом установленных моделей, и список сам переключается
  на найденный. Режим «Авто» сохраняется: следующий текст определяется
  заново, а ручной выбор языка его отключает. Если в главном окне язык
  выбран вручную, перевод выделенного текста идёт именно с него (раньше
  выбор игнорировался).

## Исправлено

- **В списках «С языка» и «На язык» было видно только семь языков.** Список
  всегда содержал все 64 языка, но высота раскрытого списка была 140 px —
  ровно семь строк, остальное скрывалось за прокруткой. Теперь видно около
  двадцати строк, а полный список доступен сразу.
- **Нет установленной модели для пары** — окно теперь спрашивает: «Открыть
  окно "Пакеты", чтобы скачать её?» и открывает его по кнопке «Да», причём
  сразу **с фильтром по недостающему языку** — в списке остаются только
  нужные пары (например, «Эсперанто → Английский»).

## Что вошло ранее в 0.99.4

- Поддержка современных пакетов Argos (1.5+): без `model/config.json` и со
  `shared_vocabulary.txt`.
- Восемь новых языков, для которых Argos публикует модели: эсперанто,
  баскский, ирландский, киргизский, португальский (Бразилия), суахили,
  тагальский, китайский (традиционный) — всего 64 языка.
- Перевод через английский проверен на реальных моделях; тесты пивота и NLLB
  снова работают в релизной сборке.

## Установка

- `tling-0.99.5-beta-setup.exe` — установщик **без моделей** (~11 МБ): модели
  ставятся из окна «Пакеты».
- `tling-0.99.5-beta-portable.zip` — портативная папка без моделей (~15 МБ),
  Python не нужен.
- `tling-0.99.5-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.5**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` ~900 МБ и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
