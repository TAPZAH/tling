**TLing** — оффлайн-переводчик для Windows. В версии 0.1009 обновлена
плавающая кнопка: значок приложения и новые жесты.

**TLing beta 0.1009 — floating button: app icon, screen OCR and mode toggle.**

## Что нового

- **Правый клик — окошко выбора режима**: «Перевод» или «Только OCR» с
  галочкой на активном пункте, рядом — «Убрать кнопку» для отключения
  самой кнопки; оформление общее с меню трея.
- **Иконка с рабочего стола** у обеих всплывающих кнопок — и у плавающей,
  и у кнопки, появляющейся рядом с курсором при выделении текста.
- **Двойной клик — распознавание экрана**: кнопка запускает выделение области
  экрана (как Ctrl+Shift+S); раньше двойной клик открывал выбор файла, он
  доступен перетаскиванием файла на кнопку и в меню трея.
- Подсказка на кнопке описывает все жесты, переводится на 4 языка.

## Что вошло в предыдущих версиях

- 0.1008: распознавание по кропу ячейки (включая вертикальные заголовки),
  чище сетка таблиц (без ложных колонок и псевдотаблиц-страниц), структурная
  модель SLANet для таблиц без линий, поворот PNG в читаемую ориентацию,
  фиксация направления перевода на документ, исправленный экспорт в Word;
- Excel/Word по сетке таблиц (merged cells, границы, ширины колонок);
  режим «Точно» с серверным детектором PP-OCRv5; китайский OCR; наложение
  перевода на изображение; режим «Только OCR»; перевод PDF (PDFium);
  перевод ячеек Excel (COM/буфер); плавающая кнопка, темы, обновления,
  история, автоопределение языка, многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.1009-beta-setup.exe` — установщик **без моделей перевода**: OCR
  (PP-OCR) включён; движки и остальное — из окна «Пакеты» / по запросу.
- `tling-0.1009-beta-portable.zip` — портативная папка без моделей перевода
  (OCR включён), Python не нужен.
- `tling-0.1009-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.1009**, автор — TAP3AH.
