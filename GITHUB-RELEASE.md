## Описание

Обновление **TLing** добавляет иконку приложения и ярлыки, а также
исправляет загрузку моделей Firefox. Включает исправление установки пакетов
Argos из версии 0.99.1.

**TLing beta 0.99.2 — app icon, shortcuts and a Firefox models fix.**

### Что нового

- **Иконка приложения** встроена в `TLing.exe`: ярлыки, панель задач и
  Проводник больше не показывают стандартную заглушку.
- **Иконка окна** — та же иконка в заголовке окна и на панели задач.
- **Ярлык на рабочем столе** теперь создаётся по умолчанию (плюс ярлык в
  меню Пуск).
- Новые иконки светлой и тёмной темы (`icon-light` / `icon-dark`) и
  мультиразмерный `app.ico` (16–256).

### Исправлено

- **Ошибка при загрузке моделей Firefox** на чистой установке
  (`directory_iterator: The system cannot find the path specified` для
  каталога `firefox-models`): список установленных моделей больше не падает,
  если каталога ещё нет.
- **Падение установки пакетов Argos** с ошибкой «Неизвестный символ
  Huffman»: распаковка ZIP-пакетов переведена на **zlib**.

### Установка

- `tling-0.99.2-beta-setup.exe` — установщик без моделей: модели ставятся
  из окна «Пакеты».
- `tling-0.99.2-beta-portable.zip` — портативная папка без моделей.
- `tling-0.99.2-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.2**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` ~900 МБ и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
