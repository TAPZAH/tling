## Описание

Обновление **TLing** исправляет установку пакетов Argos Translate.
Остальное без изменений: четыре оффлайн-движка, многоязычный интерфейс,
портативный режим.

**TLing beta 0.99.1 — fixes installing Argos Translate packages.**

### Исправлено

- **Падение установки пакетов Argos** с ошибкой «Неизвестный символ
  Huffman». Распаковка ZIP-пакетов переведена на **zlib** — самодельный
  DEFLATE-декодер не поддерживал часть корректных потоков, которые
  Python-ziplib создаёт в реальных `.argosmodel`. Проверено на настоящих
  пакетах `translate-en_de-1_9` и `translate-de_en-1_3`.
- Добавлен регрессионный тест распаковки реальных `.argosmodel`.

### Установка

- `tling-0.99.1-beta-setup.exe` — установщик без моделей: модели ставятся
  из окна «Пакеты».
- `tling-0.99.1-beta-portable.zip` — портативная папка без моделей.
- `tling-0.99.1-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.1**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` ~900 МБ и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
