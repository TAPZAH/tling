# TLing beta 0.99.6 — текст релиза для GitHub

## Tag

`v0.99.6-beta`

## Заголовок

TLing beta 0.99.6 — надёжные модели, детектор языка и новая иконка

## Описание

Версия 0.99.6 исправляет работу с оборванными моделями Firefox и делает
автоопределение языка полезным: язык распознаётся даже тогда, когда модели
для него ещё нет, и приложение сразу предлагает её скачать.

**TLing beta 0.99.6 — reliable models, language detection and a new icon.**

## Исправлено

- **Оборванная загрузка модели Firefox** больше не считается установленной:
  `model.bin` и словари проверяются по размеру. Раньше приложение пыталось
  перевести битой моделью и отвечало «Пустой ответ переводчика», теперь
  прямо называет пару и предлагает переустановить модель.
- **Автоопределение языка работает и без установленной модели**: турецкий
  текст распознаётся как турецкий, и приложение предлагает скачать `tr→en`,
  а не переводит его молча как английский.
- **Нет модели для пары** — предложение «Открыть окно "Пакеты", чтобы скачать
  её?» теперь появляется и при переводе **выделенного текста** (раньше только
  в главном окне), и сразу с фильтром по недостающему языку.
- **В списках языков не было прокрутки**: у списка из 65 пунктов отсутствовала
  полоса прокрутки и не работало колесо мыши — дальние языки было не достать.
  Добавлен `WS_VSCROLL`, а список теперь открывается с первого пункта, так что
  «Авто» и первые языки видны сразу.
- **Проверка обновлений из трея** больше не открывает настройки: результат
  приходит всплывающим сообщением, а окно настроек открывается только когда
  обновление найдено.

## Что нового

- **Новая иконка приложения** (жёлтая и синяя стрелки на прозрачном фоне) —
  на ярлыке, в окнах, в трее и у установщика.
- **Автоопределение языка источника**: пункт «Авто» в списке «С языка» —
  офлайн-детектор (60+ языков) сам переключает список на найденный язык;
  режим «Авто» сохраняется. Если язык выбран вручную, перевод выделенного
  текста идёт именно с него.
- **Список языков по алфавиту** — нужно меньше прокручивать.
- **Турбо перевод** (правый клик по иконке в трее) — перевод сразу после
  выделения текста, без кнопки у курсора.
- **Сводка «Сейчас работает»** в настройках на вкладке «Поведение».

## Что вошло ранее

- Поддержка современных пакетов Argos (1.5+): без `model/config.json` и со
  `shared_vocabulary.txt`.
- Восемь новых языков, для которых Argos публикует модели: эсперанто,
  баскский, ирландский, киргизский, португальский (Бразилия), суахили,
  тагальский, китайский (традиционный) — всего 64 языка.
- Перевод через английский; тесты пивота и NLLB снова выполняются в релизной
  сборке.
- Загрузка моделей без интернета не требуется: всё работает локально.

## Установка

- `tling-0.99.6-beta-setup.exe` — установщик **без моделей** (~11 МБ): модели
  ставятся из окна «Пакеты».
- `tling-0.99.6-beta-portable.zip` — портативная папка без моделей (~15 МБ),
  Python не нужен.
- `tling-0.99.6-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.6**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` ~900 МБ и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
