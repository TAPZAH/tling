**TLing** — оффлайн-переводчик для Windows. В версии 0.1008 доработаны
разметка документов и распознавание ячеек таблиц.

**TLing beta 0.1008 — cell-level OCR, cleaner table grids and structure fixes.**

## Что нового

- **Распознавание по кропу ячейки**: текст в таблицах читается заново по
  каждой ячейке — слова не «протекают» между соседними полями, а
  вертикальные заголовки колонок (`Наименование товара`, `Цена`, `Страна`)
  распознаются и переводятся.
- **Чище сетка Excel/Word**: ложные линии (штрихи, рамки) больше не создают
  десятки пустых колонок; у ячеек корректные границы (влияет на размер
  шрифта и фон), страница-рамка не превращается в одну огромную таблицу —
  текст письма/формы снова переводится абзацами.
- **Структурная модель таблиц SLANet** (опционально, включается с «Точным»
  OCR): определяет ячейки таблиц без линий; модель ~8 МБ скачивается по
  запросу. На документах с линованными таблицами не используется.
- **PNG с переводом** поворачивается в читаемую ориентацию.
- **Направление перевода фиксируется на документ**: смешанные ячейки
  (артикулы, `ET`, латиница) не уезжают в обратную сторону ru↔en.
- **Исправлен экспорт в Word** (файл больше не считается повреждённым).

## Что вошло в предыдущих версиях

- Excel/Word по сетке таблиц (merged cells, границы, ширины колонок);
  режим «Точно» с серверным детектором PP-OCRv5; китайский OCR; наложение
  перевода на изображение; режим «Только OCR»; перевод PDF (PDFium);
  перевод ячеек Excel (COM/буфер); плавающая кнопка, темы, обновления,
  история, автоопределение языка, многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.1008-beta-setup.exe` — установщик **без моделей перевода**: OCR
  (PP-OCR) включён; движки и остальное — из окна «Пакеты» / по запросу.
- `tling-0.1008-beta-portable.zip` — портативная папка без моделей перевода
  (OCR включён), Python не нужен.
- `tling-0.1008-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.1008**, автор — TAP3AH.
