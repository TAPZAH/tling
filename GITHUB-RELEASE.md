**TLing** — оффлайн-переводчик для Windows. В версии 0.1003 исправлена
кнопка показа оригинала в окне перевода и уточнены горячие клавиши Excel.

**TLing beta 0.1003 — show-original fixes and Excel hotkey update.**

## Что нового

- **Кнопка «показ оригинала» («О») в окне перевода**:
  - больше не закрывает окно при режиме «закрывать нажатием»;
  - не перекрывается кнопкой «Закрыть» в режиме с выделением текста
    (окно результата стало шире);
  - рисуется в цветах темы (в тёмной теме больше не белая);
  - показывает действие: «О» — показать оригинал, «П» — вернуться к переводу.
- **Excel**: базовая горячая клавиша — **Alt+E**; свою комбинацию можно задать
  в настройках. Вариант вызова «двойное Ctrl+C» убран.
- README переписан: полностью описаны возможности и все настройки.

## Что вошло в предыдущих версиях

- **Режим «Только OCR»**: распознавание области экрана без перевода; пункт
  трея (до перезапуска) или чекбокс «Только OCR всегда» в настройках.
- **OCR на PaddleOCR (PP-OCR)** через ONNX Runtime: детектор строк DBNet и
  распознаватели по письменностям (латиница, кириллица); переключатель
  движка OCR, откат на Tesseract для остальных языков.
- **Перевод PDF** (PDFium, BSD): текстовый слой или OCR скана; многостраничный
  PDF — один `.docx`/`.xlsx`.
- **Перевод изображений** в Word/Excel или PNG с наложением перевода
  (замена текста в тех же позициях, таблицы по колонкам, жирные заголовки).
- **Перевод выделенных ячеек Excel** (COM/буфер, горячая клавиша).
- Перевод области экрана, кнопка «Добавить», плавающая кнопка, темы,
  проверка обновлений, история копирований, автоопределение языка,
  турбо-перевод, многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.1003-beta-setup.exe` — установщик **без моделей перевода**: OCR
  (PP-OCR) включён; движки и остальное — из окна «Пакеты» / по запросу.
- `tling-0.1003-beta-portable.zip` — портативная папка без моделей перевода
  (OCR включён), Python не нужен.
- `tling-0.1003-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.1003**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
