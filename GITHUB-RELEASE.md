TLing beta 0.99.9 — перевод Excel и изображений

## Описание

**TLing** — оффлайн-переводчик для Windows. В обновлении 0.99.9 добавлены
перевод выделенных ячеек Excel, перевод изображений в Word/Excel и
плавающая кнопка для перетаскивания файлов; интерфейс — единая
светлая/тёмная тема.

**TLing beta 0.99.9 — Excel and image translation, refreshed light/dark UI.**

## Что нового

- **Перевод выделенных ячеек Excel** (горячая клавиша, по умолчанию
  Ctrl+Alt+T, или двойное Ctrl+C):
  - **COM** — прямое подключение к открытому Excel, формулы не трогаются;
  - **буфер обмена** — лёгкий режим, без доступа к Excel;
  - **авто** — COM, затем буфер обмена;
  - в каждую ячейку добавляется перевод через « / » или « - ».
- **Перевод изображений в Word/Excel** (кнопка «Изображение…», трей,
  «Область экрана → Word/Excel»): распознавание текста офлайн (Tesseract),
  автоопределение поворота, примерная разметка — таблицы, колонки, размер
  шрифта и выравнивание.
- **Плавающая кнопка** (включается в меню трея): перетащите на неё файл —
  перевод начнётся сразу; двойной клик открывает выбор файла.
- **Кнопка «Добавить»** в окне перевода — оригинал + перевод через
  настраиваемый разделитель.
- **Своё окно проверки обновлений** в стиле приложения с кнопками
  «Да»/«Нет».
- **Единое оформление приложения**: светлая и тёмная темы, заголовок окна
  следует теме, современный системный шрифт, аккуратные списки и кнопки.
- Убрана отдельная горячая клавиша перевода выделения — остались Ctrl+C+C и
  кнопка у курсора.

## Что вошло в предыдущих версиях

- **Перевод области экрана (OCR)** — выделите рамкой текст на экране, он
  распознаётся офлайн (Tesseract) и переводится.
- **Проверка обновлений при запуске** — тихо, отключается чекбоксом.
- **Направление перевода** — в обе стороны; при «С языка» = «Авто» есть
  третий список для случая, когда язык текста совпал с «На язык».
- **Движок «Google (онлайн)»** — без ключа или со своим ключом API.
- **Автоопределение языка источника**, турбо-перевод, история копирований,
  многоязычный интерфейс, автозагрузка.

## Установка

- `tling-0.99.9-beta-setup.exe` — установщик **без моделей**: движки и
  языковые данные OCR ставятся из окна «Пакеты» / по запросу.
- `tling-0.99.9-beta-portable.zip` — портативная папка без моделей,
  Python не нужен.
- `tling-0.99.9-beta-src.zip` — исходники.

Нужны Windows 10/11 x64. Версия **beta 0.99.9**, автор — TAP3AH.

Сборки с предустановленными моделями (`setup-with-models.exe` и
`portable-with-models.zip`) собираются локально скриптом
`cpp\build_release.ps1` и на GitHub не выкладываются.
